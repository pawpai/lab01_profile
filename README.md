# Lab L1 · About me

Flutter app for COE67-332. The profile shows the student's name and ID. Each tap on Like increments the counter using `setState`.

## Run and test

Start an Android emulator, then run these commands from the project directory.

```sh
flutter pub get
flutter devices
flutter run -d <emulator-id>
```

```sh
flutter analyze --no-fatal-infos
flutter test
```

The experiment observations and test results are in `answers.md`.
